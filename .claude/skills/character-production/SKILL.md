# Character production

## Inputs to read first
- `CLAUDE.md` (approval and originality rules)
- `characters/character-bible.md`
- `brand/visual-style.md`
- `age-groups/<age>.md`

## Process
1. **Concept**: role in stories, rugby position or skill, personality, values they model.
2. **Profile**: write `characters/<age>/<slug>.md` from the bible template. Status: `PROPOSED`.
3. **Owner review**: present the profile and open questions.
4. **Approval**: only after explicit owner approval, set status `APPROVED (owner, YYYY-MM-DD)` and add the character to the bible index.
5. **Reference sheet**: after approval, hand off to `illustration-production` for a visual reference plan.

## Character statuses
`PROPOSED` → `APPROVED` → (`RETIRED`)

## Rules
- Characters must be original. They must not resemble competitor characters, real people or existing IP.
- Use diverse, inclusive representation with no stereotypes.
- Visual details (colours, outfits) must use the brand colour system once it is confirmed. Until then, mark them `TO BE CONFIRMED`.
- Keep characters consistent across books. Any change to an approved character needs owner approval.
